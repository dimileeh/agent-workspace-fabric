# Code of Conduct

## Our pledge

In the interest of fostering an open and welcoming environment, everyone who
participates in the Agent Workspace Fabric (AWF) project — contributors,
maintainers, and users — pledges to make participation a harassment-free
experience for everyone, regardless of background or identity.

## Our standard

This project adopts the **[Contributor Covenant, version 2.1][covenant]** as its
code of conduct. Please read it: it describes the behavior we expect, the
behavior we will not tolerate, and the responsibilities of maintainers.

In short: be respectful, assume good faith, give and accept constructive
feedback gracefully, and focus on what is best for the community and the
project. Harassment, personal attacks, and other unacceptable behavior described
in the Covenant are not tolerated in any project space (issues, pull requests,
discussions, and any other channel).

## Scope

This Code of Conduct applies within all project spaces and also when an
individual is officially representing the project in public spaces.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the
maintainers at **conduct@aira.pro**. All reports will be reviewed and
investigated promptly and fairly, and the privacy and security of the reporter
will be respected.

## Enforcement

Maintainers are responsible for clarifying and enforcing this Code of Conduct and
will take appropriate, fair corrective action in response to any behavior they
deem inappropriate, threatening, offensive, or harmful, following the
[Contributor Covenant enforcement guidelines][enforcement].

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
[enforcement]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
