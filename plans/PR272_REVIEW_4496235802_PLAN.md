# PR272 Review 4496235802 Plan

## Problem Statement

The PR review identified three small but safety-relevant gaps in preserved active
execution recovery:

- `pushing` workspaces with an already active `worker_restart` validation
  recovery operation are excluded from the `_recover_preserved_active_execution`
  redispatch fast-path.
- The repository claim helper only claims `running` workspaces; this is
  intentional because preserved `validating` and `pushing` workspaces are
  rewound to `running` before executor claim, but the invariant is undocumented.
- The stale-failure salvage blocking list intentionally omits `SALVAGE_BLOCKED`
  and `SALVAGE_NOT_POSSIBLE`; that omission needs a guard comment to prevent
  future livelock regressions.

## Scope

unit tests. Do not alter branch management, PR monitor behavior, stale cleanup
policy, or unrelated recovery flows.
