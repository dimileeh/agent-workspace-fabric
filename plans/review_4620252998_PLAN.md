# Review 4620252998 Plan

## Problem Statement And Scope

Address the review-level comment for PR #396 without widening the cleanup
change. The review identified that the missing-workspace compose teardown
fallback is skipped when `cleanup_enabled=False`, even though that flag is a
filesystem deletion policy and callers may still supply a compose teardown
callback to reap Docker resources. The review also requested a short comment in
the PR monitor exception path documenting why tracked compose teardown results
may be incomplete when callbacks raise.

## Requirements Checklist

- Update the missing-workspace single-workspace GC regression so
  `cleanup_enabled=False` still permits fallback compose teardown when a
  callback is supplied.
- Preserve existing behavior for known workspaces where `cleanup_enabled=False`
  keeps runtime side effects and filesystem cleanup disabled.
- Remove only the missing-workspace fallback dependency on `cleanup_enabled`;
  keep compose teardown gated by the existing callback/fallback mechanisms.
- Add a concise comment in the monitor GC exception path documenting that local
  tracking may be incomplete if the teardown callback raises before recording
  the result, and that auth-overlay unmount remains gated on a tracked success.
- Run focused tests for the changed GC fallback and monitor completion GC
  behavior only. Full AWF/GitHub validation remains managed by AWF after agent
  completion.

## Implementation Steps

1. Update the missing-workspace cleanup-disabled GC test to expect the fallback
   compose teardown call and result.
2. Run that targeted test and confirm it fails against the current code.
3. Remove the `cleanup_enabled` guard from the missing-workspace fallback in
   `run_workspace_filesystem_gc`.
4. Add the explanatory comment near the exception-path tracked teardown lookup
   in `_gc_completed_workspace_filesystem`.
5. Run focused tests covering the changed GC path and monitor completion GC
   module.
6. Record validation evidence in `plans/review_4620252998_VALIDATION.md`.
