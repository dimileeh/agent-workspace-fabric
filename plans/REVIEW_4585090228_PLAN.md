## Problem Statement And Scope

Address the remaining review-level concerns in PR comment issue:4585090228:

- `_source_runtime_not_yet_released` intentionally blocks failed legacy
  null-runtime rows with no reservation, but the `return not reservations`
  polarity is easy to misread.
- Planning-scope auto-retry currently bypasses the source-runtime release gate,
  creating a port-bearing retry workspace that is expected to fail later in the
  provisioner companion-port check before cleanup releases the source runtime.

Scope is limited to retry runtime-release readability, planning-scope
auto-retry admission behavior, and focused regression coverage.
