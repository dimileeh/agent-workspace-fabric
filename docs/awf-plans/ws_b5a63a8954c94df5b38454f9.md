## Matrix Content To Add

The dedicated document will include:

- Role contract:
  - REST is the canonical AWF control-plane API and schema source of truth.
  - CLI is a JSON-first operator convenience layer over REST or local service diagnostics.
  - MCP is a first-class parity client for agent orchestrators, not shell access.
- Status vocabulary such as `MCP implemented`, `MCP partial`, `MCP missing/backlog`, `CLI absent`, and `out of scope`.
- A parity matrix with columns for capability, canonical REST endpoint, CLI command when available, MCP tool when available, status, and notes/backlog.
- Rows for the required surfaces:
  - Workspaces: `POST /v1/workspaces`, `POST /v2/workspaces`, `GET /v1/workspaces`, `GET /v1/workspaces/{workspace_id}`; CLI `awf workspace create/list/show`; MCP `awf_create_workspace`, `awf_create_workspace_v2`, `awf_list_workspaces`, `awf_get_workspace`, `awf_wait_for_workspace`.
  - Merge queue: `GET /v1/merge-queue`; MCP `awf_list_merge_queue`; CLI absent/backlog if desired.
  - Task attempts: `GET /v1/tasks`, `GET /v1/tasks/{task_ref}/attempts`; MCP `awf_list_tasks`, `awf_list_task_attempts`; CLI absent/backlog.
  - Validation provenance: `GET /v1/workspaces/{workspace_id}/validation`; MCP `awf_list_workspace_validation`; CLI absent/backlog.
  - Stale reasons: `GET /v1/workspaces/{workspace_id}/stale-reasons`; MCP `awf_list_workspace_stale_reasons`; CLI absent/backlog.
  - Artifacts: `GET /v1/workspaces/{workspace_id}/artifacts` and `GET /v1/workspaces/{workspace_id}/artifacts/download`; MCP `awf_list_workspace_artifacts` for metadata; mark content/download parity as missing/backlog unless intentionally excluded by security policy.
  - Metrics: `GET /v1/metrics/failures/summary`, `/workspaces/summary`, `/resources/saturation`, `/slo`; MCP `awf_get_failure_analysis_summary`, `awf_get_workspace_reliability_summary`, `awf_get_resource_saturation_summary`, `awf_get_slo_metrics_summary`.
  - Locks and overlap graph: `GET /v1/locks`, `GET /v1/locks/overlap-graph`; CLI `awf locks list`; MCP `awf_list_locks`, `awf_get_overlap_graph`.
  - Service health/status: `GET /healthz`, `GET /readyz`; CLI `awf service status` and `awf service doctor`; MCP `awf_get_service_health`, `awf_get_service_readiness`.
  - Runtime/logs/operations: `GET /v1/workspaces/{workspace_id}/runtime`, `/logs`, `/logs/{stream_id}`, `/operations`, and global `/v1/operations`; CLI `awf workspace runtime/operations/logs/log`; MCP `awf_get_workspace_runtime`, `awf_list_workspace_logs`, `awf_read_workspace_log`, `awf_list_workspace_operations`, `awf_list_operations`, `awf_get_operation`.
  - Safe operator actions: cancel, stop, destroy, remonitor, validate, refresh, rebase, retry. Mark existing MCP tools for cancel/stop/destroy/remonitor/validate; mark refresh/rebase/retry as missing MCP backlog with corresponding REST endpoints and CLI `awf workspace retry` where available.
- Security boundary:
  - MCP may expose only AWF-managed runtime snapshots, durable logs, artifact metadata/content when explicitly bounded, operations, and safe control-plane operations.
  - MCP must not expose arbitrary shell, unrestricted Docker exec, host filesystem browsing, raw container exec, or token/secret material.

## Risks And Assumptions

- Advisory overlap exists on `docs/**`, `README.md`, and `tests/unit/mcp/**`; if related target-branch work lands first, AWF may require stale overlap revalidation.

- Current MCP control tools expose idempotency keys but not every REST concurrency header. The document should call out any mismatch plainly.
