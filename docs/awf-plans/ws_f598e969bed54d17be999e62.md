## Tests to Write First
- None. This is a documentation refactoring task.

## Validation Commands
- `wc -l README.md` to ensure it is under 300 lines.
- `grep -r "\[.*\](.*\(\.md\).*)" README.md` to review the introduced links.
- Write a quick bash script to verify all local relative `.md` links in `README.md` actually exist.

## Risks, Assumptions, and Explicit Non-Goals
- **Risk:** Existing external links pointing to specific anchor tags in `README.md` may break.
- **Assumption:** The extracted sections from the current `README.md` are sufficient content for the new documentation files and do not require heavy rewriting.
- **Explicit Non-Goal:** Rewriting documentation wholesale. The strategy is to move, link, and summarize conservatively.
- **Explicit Non-Goal:** Owning or writing the detailed "Start Here quickstart" content.
- **Explicit Non-Goal:** Implementing OpenAPI artifact generation or PR adoption docs.
