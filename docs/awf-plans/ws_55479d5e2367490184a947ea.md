# Copy-Paste Onboarding Prompts Plan

## Goal

Implement the P1 backlog slice: add copy-paste onboarding prompts for Codex, Claude Code, Gemini, OpenCode, and OpenClaw. A first-time evaluator should be able to copy a prompt for their agent that says, in provider-appropriate language: inspect this project, generate `.awf/workspace.yml`, preview it, launch a smoke workspace, then implement feature X through AWF. Link these prompts from the existing onboarding docs and keep them generic for any repository. Add a docs/status consistency test if the repo already has one suitable for these docs.

## Implementation Steps

1. Append the failing docs consistency test.
2. In `docs/PROJECT_ONBOARDING.md`, after the existing generic "One-message prompt", insert per-provider sections.
   - Use clear `### Codex` / `### Claude Code` / `### Gemini` / `### OpenCode` / `### OpenClaw` headings.
   - Each section contains a single fenced text or plain-text block that an evaluator can copy and paste into the respective CLI/chat.
   - Language should be provider-appropriate but remain generic (no Aira-specific assumptions).
   - Example structure for Codex:
     ```text
     Inspect this repository for AWF onboarding. Do not launch a workspace yet.

     1. Run `awf init .` to inspect the repo.
     2. Run `awf profile init . --write` to generate `.awf/workspace.yml`.
     3. Run `awf profile preview .` to preview the resolved profile.
     4. Run `awf profile init . --include-smoke-request` to produce a smoke workspace request, then submit it to validate the profile end-to-end.
     5. Once the smoke workspace succeeds, implement the requested feature through AWF by creating a real workspace with an appropriate task prompt and owned paths.

     Keep secrets as profile declarations or `${VAR}` placeholders; never write raw secret values.
     ```
   - Adapt wording slightly per provider (e.g., Claude Code may prefer “I will inspect…”, Gemini/Google may prefer imperative steps, OpenCode may reference `opencode run`).
3. In `README.md`, update the onboarding reference to mention that copy-paste prompts for each provider are available in `docs/PROJECT_ONBOARDING.md`.
4. In `TODO/pre-gke-industrial-readiness.md`, flip the checkbox at line 544 from `[ ]` to `[x]`.
5. Run tests until green.
