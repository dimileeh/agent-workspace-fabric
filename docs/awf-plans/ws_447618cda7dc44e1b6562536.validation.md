- **R1 (critical regression):** net `base..HEAD` committed paths include
  `src/foo.py` and the fix-pass stages only `…conformance.json` → guard returns

  finish, `has_known_non_plan_output` becomes `True`, execution proceeds.
- **R3:** net committed output empty + staged plan-only → still fails
  `PLAN_ONLY_OUTPUT`.
- **R4:** net committed output itself plan-only (only the plan `.md`) + staged
  plan-only → still fails.
- **R-revert:** real file committed then reverted (net `base..HEAD` empty) +
  staged plan-only → still fails; `_committed_paths_since` is consulted with the
  in-scope `worktree_path` and `base_commit` (proves net git state is read, not a
  stale flag).
- **Helper units:** real staged path → `False` without a git call (short-circuit);
  staged plan-only + committed real → `False`; + committed empty → `True`;
  + committed plan-only → `True`.
