## Coverage reasoning (full gate owned by AWF/CI)

Every new branch is exercised by a focused test, so total coverage does not drop:

- `_resolve_full_commit_sha` early-return (`len(sha) >= 40`) → unit early-return test.
- resolve success path → (a).
- malformed-payload raise (`resolved is None or len < 40`) → short-hash and
  non-dict tests.
- HTTP/transport failure propagation reuses existing `_request_json` paths → (e).
- `_remember_pr` `head_sha` param and `fetch_pr_status` reorder → exercised by
  every `fetch_pr_status` test (abbreviated and full).

The whole-suite run, the aggregate 99% coverage gate, `ruff format --check` over
the full tree, and merge gating are executed by AWF's validation phase and
GitHub CI after the agent phase, per the workspace contract.
