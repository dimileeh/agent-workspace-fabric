## Objective

Add an inspected, checked-in shell installer at `packaging/install.sh` that installs the
`agent-workspace-fabric` package by:

1. Resolving the AWF install manifest (`awf-install-manifest.json`) for a requested
   `--version` / `--channel`.
2. Downloading the pinned wheel artifact named in the manifest.
3. Verifying the artifact `sha256` against the manifest **before** any install mutation.
4. Installing from the **locally verified wheel** via `uv tool install` (default), with a
   `pipx install` fallback when configured via `--method pipx`.
5. Verifying `awf` reachability after install and printing correct PATH advice for
   zsh/bash/fish when the install dir is not on `PATH`.

Plus supporting `--dry-run`, `--install-dir`, `--uninstall`, and `--help`, with conservative
trust behavior: checksum mismatch, unsupported OS/arch, and unmanaged uninstall targets all
abort before mutation with a stable reason token.

## Trust And Behavior Contract (acceptance criteria mapping)

| Acceptance criterion | Installer behavior |
| --- | --- |
| Checksum mismatch aborts before install | Hash the downloaded wheel, compare to manifest `sha256`; on mismatch print `CHECKSUM_MISMATCH` + artifact URL and exit non-zero **before** any `uv`/`pipx` call. |
| Unsupported OS/arch fails before mutation | Validate `uname -s` ∈ {Darwin, Linux} and `uname -m` ∈ arch allowlist; otherwise print `UNSUPPORTED_PLATFORM` and exit before download/install. |
| Dry-run avoids install mutation and explains planned actions | `--dry-run` resolves + verifies the plan (manifest, artifact, checksum if fixture available) and prints the ordered planned actions, but never calls the install method and never writes shell rc files. |
| Uninstall removes only AWF-managed files | `--uninstall` only removes installs owned by `uv tool` / `pipx` / the recorded AWF install dir; an `awf` resolving outside those is refused with `UNINSTALL_REFUSED_UNMANAGED` and no deletion. |
| PATH advice correct for zsh/bash/fish | Shell detection (`$SHELL`, overridable) selects the right rc file and the right export syntax (`export PATH=...` for bash/zsh, `fish_add_path` / `set -gx PATH` for fish). |
| PATH target not reachable (failure-mode table) | After install, if `awf` is not executable on the resolved `PATH`/install dir, print `AWF_NOT_REACHABLE` plus the exact shell fix and exit non-zero — never claim success. |

### Stable installer reason tokens (shell-owned contract)

The installer is intentionally a standalone POSIX-friendly bash script and must **not** depend
on the Python first-run error catalog (that is T03's surface). It emits its own stable reason
tokens on stderr so tests can assert behavior without encoding prose:

- `UNSUPPORTED_PLATFORM` — OS or arch not in the supported allowlist.
- `MISSING_DEPENDENCY` — required host tool (download tool, sha256 tool, install method) absent.
- `MANIFEST_UNAVAILABLE` — manifest could not be resolved/fetched.
- `MANIFEST_INVALID` — manifest missing required fields / no matching wheel artifact.
- `DOWNLOAD_FAILED` — artifact download failed.
- `CHECKSUM_MISMATCH` — downloaded artifact sha256 != manifest sha256.
- `INSTALL_METHOD_FAILED` — `uv tool install` / `pipx install` returned non-zero.
- `AWF_NOT_REACHABLE` — install reported success but `awf` is not runnable.
- `UNINSTALL_REFUSED_UNMANAGED` — `--uninstall` target is not an AWF-managed install.
- `BAD_USAGE` — unknown flag / invalid argument combination.

## CLI Surface

```text
packaging/install.sh [options]

  --version <X.Y.Z>      Install a specific package version (pins manifest/tag).
  --channel <name>       stable | prerelease (default: stable). Used when --version omitted.
  --method <name>        uv | pipx (default: uv). pipx is the configured fallback.
  --install-dir <path>   Bin directory for the awf shim / reachability + PATH advice.
  --dry-run              Resolve + explain planned actions; no install mutation, no rc writes.
  --uninstall            Remove an AWF-managed install only; refuse unknown executables.
  --help                 Print usage and exit 0.
```

### Testability seams (no real release / no live network by default)

These env overrides keep fixture tests hermetic and are the core design seam:

- `AWF_INSTALL_MANIFEST` — path or `file://` URL to a local manifest JSON (bypasses release
  resolution). Primary hook for fixture dry-run/checksum tests.
- `AWF_INSTALL_BASE_URL` — override the GitHub Releases base used to resolve a manifest by
  version/channel (so a fixture HTTP/`file://` root can stand in).
- The artifact fetch helper accepts `https://`, `http://` (curl/wget) **and** `file://`/local
  paths (`cp`), so fixture manifests can point `url` at a local fixture wheel.
- `uname`, `uv`, `pipx`, `awf`, and the download/sha tools are resolved via `PATH`, so tests
  inject stub executables on a temp `PATH` to deterministically drive success/failure and to
  simulate OS/arch without a real cross-platform host.
- Optional `--shell <name>` (or `$SHELL`) selects the shell for PATH advice in tests.

Defaults with no overrides: resolve the manifest from GitHub Releases for the repo
(`https://github.com/dimileeh/aira-agent-workspace-fabric`), matching the T11/RELEASING trust
chain. Network is only used in the real (non-fixture) path.

## Tests To Write First (strict TDD)

Write/observe failing tests before the script exists, then implement the smallest green script.
Shared `conftest.py` fixtures:

- `installer_path` → absolute path to `packaging/install.sh`.
- `fake_wheel(tmp_path)` → writes a deterministic wheel file
  (`agent_workspace_fabric-<ver>-py3-none-any.whl`) and returns path + true sha256.
- `manifest_factory(tmp_path)` → writes a T11-shaped `awf-install-manifest.json` whose wheel
  artifact `url` is `file://<fake_wheel>` and `sha256` is overridable (true vs wrong).
- `fake_bin(tmp_path)` → temp dir prepended to `PATH` holding stub `uname`, `uv`, `pipx`,
  `awf`, `curl`/`wget`, `sha256sum`/`shasum`; each stub configurable to succeed/fail and to
  record invocations to a log file (so tests assert "install method not called" in dry-run /
  abort paths).
- `run_installer(args, env)` → `subprocess.run(["bash", installer_path, *args], env=...,
  text=True, capture_output=True)` with a hermetic `HOME`, `PATH`, `SHELL`, and
  `AWF_INSTALL_MANIFEST`.

Planned tests (each asserts exit code, reason token presence, and mutation/no-mutation via the
stub invocation log):

1. **Syntax** — `bash -n packaging/install.sh` exits 0. (`test_install_sh_syntax.py`)
2. **Help** — `--help` exits 0 and lists every documented flag. No reason token, no mutation.
3. **Dry-run macOS** — stub `uname` → `Darwin`/`arm64`, fixture manifest+wheel, `--dry-run`:
   exit 0, prints ordered planned actions (resolve → download → verify sha256 → `uv tool
   install <wheel>` → verify awf), install stub **not** invoked, no rc-file writes under `HOME`.
4. **Dry-run Linux** — stub `uname` → `Linux`/`x86_64`, same assertions.
5. **Checksum mismatch** — manifest `sha256` wrong for the fixture wheel: exit non-zero,
   `CHECKSUM_MISMATCH` + artifact URL on stderr, install stub **not** invoked (abort before
   mutation).
6. **Unsupported OS** — stub `uname` → `MINGW64_NT`/`x86_64`: `UNSUPPORTED_PLATFORM`, non-zero,
   no download/install.
7. **Unsupported arch** — stub `uname` → `Linux`/`ppc64le` (or `i686`): `UNSUPPORTED_PLATFORM`,
   non-zero, no download/install.
8. **Install-method failure** — stub `uv` exits non-zero on `tool install`: `INSTALL_METHOD_FAILED`,
   non-zero, error surfaced (stderr captured, reason preserved — not swallowed).
9. **pipx fallback** — `--method pipx`, stub `pipx` succeeds: pipx path used (asserted via stub
   log), `uv` not used for install; success only if reachability passes.
10. **Reachability failure** — install stub exits 0 but no runnable `awf` on `PATH`/install dir:
    `AWF_NOT_REACHABLE` + exact shell fix, non-zero exit (no false success).
11. **PATH advice** — parametrized `SHELL` ∈ {zsh, bash, fish}: assert correct rc target and
    syntax (`~/.zshrc` + `export PATH=`, `~/.bashrc`/`~/.bash_profile` + `export PATH=`,
    `~/.config/fish/config.fish` + `fish_add_path`/`set -gx PATH`).
12. **Uninstall managed** — stub `uv tool list`/uninstall reports an AWF-managed `awf`:
    `--uninstall` calls `uv tool uninstall agent-workspace-fabric`, exit 0.
13. **Uninstall unmanaged refusal** — `awf` resolves to an unmanaged location (e.g.
    `<fake_bin>/awf` not owned by uv/pipx/install-dir): `UNINSTALL_REFUSED_UNMANAGED`,
    non-zero, **no** deletion of the unmanaged file.

## Risks, Assumptions, And Mitigations

Risks:

- **macOS bash 3.2.** Default macOS bash is 3.2; avoid bash-4 features (associative arrays,
  `${var,,}`, `mapfile`/`readarray`). Mitigation: lowercase via `tr`, iterate with `while
  read`, keep functions POSIX-friendly; validate with `bash -n` and keep logic simple.
- **Cross-platform sha256 tool.** Linux `sha256sum` vs macOS `shasum -a 256`. Mitigation:
  detect at runtime; fail with `MISSING_DEPENDENCY` if neither exists; tests stub both.
- **jq availability.** `jq` is not guaranteed on target hosts. Mitigation: parse the manifest
  with portable `grep`/`sed`/`tr` against the stable, sorted T11 JSON shape (or a minimal POSIX
  parser), and keep the matched keys (`name`, `url`, `sha256`, `kind=="wheel"`) explicit. Add a
  `MANIFEST_INVALID` failure when the wheel artifact cannot be located.
- **No `shellcheck`/`shfmt`/`pipx` in this workspace.** Mitigation: rely on `bash -n` locally;
  pipx-path coverage uses a stub `pipx` on `PATH`; treat shellcheck as a CI/T16 concern, not a
  required local gate. Do not add a hard dependency on tools absent here.
- **Real-network/real-release coupling in tests.** Mitigation: all default tests use
  `AWF_INSTALL_MANIFEST` + `file://` fixtures and stub binaries; no test hits GitHub or installs
  the real package.
- **False-green install.** A passing install command does not prove `awf` works. Mitigation:
  mandatory post-install reachability check that fails with `AWF_NOT_REACHABLE` and prints the
  exact shell fix — never report success on an unreachable binary.
- **Destructive uninstall.** Mitigation: uninstall only acts on uv/pipx/recorded-install-dir
  managed locations; anything else is refused (`UNINSTALL_REFUSED_UNMANAGED`) with no deletion;
  a regression test proves an unmanaged `awf` file survives.
- **Reason tokens not hidden by retries.** No silent retries; failures preserve their reason
  token and the underlying tool stderr.

Assumptions:

- Target branch is `development`; AWF owns branch management, push, and PR creation
  (auto-merge enabled for this feature PR).
- T11 manifest schema (`schema_version: 1`, artifact `kind`/`name`/`platform`/`sha256`/`url`,
  pinned `releases/download/v<version>/...` URLs, empty `signatures`) is the stable contract
  this installer consumes; the wheel artifact has platform `os/arch = any`.
- The canonical repo URL remains `https://github.com/dimileeh/aira-agent-workspace-fabric`
  until renamed (per RELEASING.md).
- macOS + Linux are the only supported platforms in this slice; `--method` is `uv` (default)
  or `pipx`.
- `bash`, `uv`, a download tool, and a sha256 tool are available on a real install host; the
  workspace already provides `bash` and `uv` for focused tests.
