# AWF plan artifacts

The `docs/awf-plans/` directory stores AWF-generated workspace plan and
conformance artifacts (`ws_<id>.md`, `.conformance.json`, and related
validation outputs) produced by the self-dogfood workflow.

These files are internal operator metadata for workspace execution and
merge/review provenance; they are not part of the end-user product
documentation. The generated files are intentionally ignored in the public
repository; only this README is tracked to document the local artifact
directory.
