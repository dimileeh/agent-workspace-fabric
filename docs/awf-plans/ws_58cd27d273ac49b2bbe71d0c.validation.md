## Decision encoded (owner ruling)

Wrong-base-correctness wins over credential-preservation for an unverifiable base: a
NON-EMPTY overlay `upper` that is neither pinned-to-an-on-disk base nor pin-matched to the
current-host signature, with no live overlay still mounted, is discarded and rebuilt from
the current host (creds re-pulled ⇒ no operator-visible loss), and the discard is made
loud via `CLAUDE_AUTH_OVERLAY_UNPINNED_UPPER_DISCARDED_REBUILT`. Post-mount pinning is
preserved; no durable pre-mount pin was introduced.
