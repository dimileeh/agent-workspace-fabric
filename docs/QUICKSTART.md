# Start Here Quickstart

> **Note:** This quickstart guide is currently a stub. For the full installation and setup instructions, please see [Getting Started](GETTING_STARTED.md).

## 3-Minute Bootstrap

1. **Install AWF:**
   ```bash
   uv tool install aira-awf
   ```

2. **Initialize local services:**
   ```bash
   awf init
   ```

3. **Verify:**
   ```bash
   awf service status --format pretty
   ```

For repository onboarding, see [Project Onboarding](PROJECT_ONBOARDING.md).
