Agent Workspace Fabric

The control plane that runs AI coding agents as disciplined contributors. Dependencies flow left → right; the agent owns code changes, AWF owns lifecycle & policy, GitHub/BitBucket stay the source of truth.

Client surfaces

api/ FastAPI /v1
Thin REST routes; no business logic. Schemas reused by MCP.
cli/ Typer · awf
httpx client over REST. Needs a running API.
mcp/ FastMCP
In-process server for AI assistants; mirrors the REST contract 1:1.
→

Business logic

service/
Stateless operations over the DB: WorkspaceService, controls, scheduler, capacity, GC, merge queue.
state machine
Guards every status transition. Direct status= writes are bugs.
→

Orchestration

control/worker
Polls the DB, claims pending workspaces via leases, dispatches each cycle.
control/executor
Drives one workspace: agent run → validate → push → PR → monitor handoff.
runtime/ · adapters/
PR-monitor loop + Plan→Execute→Compare; one run() contract per agent CLI.
→

Execution substrate

node/ git worktrees
Per-repo bare mirrors + linked worktrees, chowned to the unprivileged agent.
node/ Compose stacks
One per-workspace Docker Compose stack, rendered from a Jinja2 template.
forge
GitHubBitBucket via one ForgeClient seam.
Workspace task lifecycle  ·  guarded by the state machine
requested▸ provisioning▸ ready▸ running▸ validating▸ pushing▸ monitoring_pr▸ completed · failedcancelleddestroyed
monitoring_pr — AWF as PR owner
A pure decision core returns exactly one action: address comments, report CI failure, sync base, wait for CI, merge, or notify a human. Merge gates are conservative: comments addressed, checks green, mergeable, not behind, final settle.
Cross-cutting foundation
db/ async SQLAlchemy repos (Postgres) · common/ forge clients, redaction, audit, reason codes · profiles/ the workspace.yml schema (runtime, services, phases, validation, security, secrets).
Invariants that bite
Transitions route through the state machine · repositories flush, the boundary commits · reason codes flow end-to-end · redaction is mandatory · profiles resolve once at provision time.
